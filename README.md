# Shop Performance Analysis
## Overview

A data analytics project analyzing 50,000 retail orders to understand sales, customers, products, payments, and revenue performance.

### Objectives
Analyze sales and revenue trends
Identify top products and categories
Analyze customer segments and cities
Examine payment and order statuses
Create business KPIs and dashboards
Tools
Python / Pandas – Data cleaning and analysis
SQL – Data analysis and KPIs
Power BI – Dashboard and visualization
GitHub – Project documentation and version control
Dataset

The dataset contains 25 columns, including customer, order, product, payment, quantity, discount, and revenue information.

### Workflow

Data → Cleaning → Analysis → SQL → KPIs → Power BI Dashboard → Insights

Key Skills

Data Cleaning • Python • Pandas • SQL • Power BI • Data Visualization • Business Analysis
